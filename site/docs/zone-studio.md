# Zone Studio

Zone Studio is the interactive studio for shaping radar detection zones
and sensor range bands in your rooms: lay out detection and exclusion
zones over a live canvas, tune range, and watch tracked targets move.

It runs as a Home Assistant add-on. Install it from the Sense360 add-on
repository and open it from your Home Assistant sidebar:

- [Add the Sense360 add-on repository](https://github.com/sense360store/sense360zones)
- [Zone Studio user guide](https://github.com/sense360store/sense360zones/blob/main/zone-studio/DOCS.md)

The user guide — including zone drawing, applying zones to the device,
and reverting to what the device holds — lives with the add-on and is
always current for the version you install.
